Structure & Movement

This framework attempts to understand reality from first principles by observing that anything can be seen through two lenses: structure — the arrangements, patterns, and interfaces through which information flows — and movement — the actions, changes, and processes that reshape those arrangements over time. These are not separate things. A law of movement is itself a structure. A structure is never truly still. They are two perspectives on the same reality, useful precisely because they reveal different aspects of it.

The practical value is in what this reveals about control. Some structures and movements are within our agency — which interfaces we build, which compositions we try, which direction we pursue. Others are not — the environment changes, phenomena behave as they behave, other systems push back. Good practice is to be precise about what we can consciously shape, design it well, and build resilience for everything we cannot. Because structure is described here through continuous, measurable properties, it offers a foundation for systematic optimisation and discovery — whether by researchers or by AI exploring the space of possible compositions.

The biosignal work below — heart-brain coupling, physiological sensing, adaptive interfaces — is the current application.

Lens 1
Structure
The arrangements through which information is transduced, connected, and made legible. In this work, we call them interfaces. Sensors, models, language, and displays all belong to the same class — differing on continuous properties like input bandwidth, prior knowledge, resolution, and output fidelity, not on kind. A sufficiently powerful sensor can replace a model. A sufficiently knowledgeable model can replace a sensor. Interfaces also compose: multiple interfaces working together form a combined interface with emergent properties.
Lens 2
Movement
The processes that change structure over time. All action is movement. Learning is the specific form of movement that reshapes structure itself — not just operating through interfaces, but improving them. The environment also moves, changing structure whether we intend it or not.

Core principles
Structure and movement are two lenses, not two things
A law of movement is itself a pattern — a structure. A structure is never truly still — it degrades, evolves, gets composed. The distinction is a practical tool for understanding, not an ontological claim.
No categories, only properties
An ECG sensor and TRIBE v2 are the same kind of thing. One has high physical input and low prior knowledge; the other, the inverse. The distinction between sensor and model is quantitative, not qualitative.
Interfaces compose
Multiple interfaces working together form a combined interface with emergent properties. The combination can perceive phenomena invisible to any component alone.
Causation is resolution-dependent
Every interface operates at a particular resolution. At coarse resolution, causal direction appears clear. At finer resolution, it dissolves into coupling and co-arising. The arrow of causation is a property of the observing interface, not of the phenomenon itself.
Agency is in the conscious shaping
Some structure and movement are within our control — which interfaces we build, which compositions we try, which learning we pursue. The rest — the environment, the phenomena, the responses of other systems — we work with but do not control. The framework helps distinguish between the two.

Whether directionality is always resolution-dependent, or fundamental at some scale

This tab expands on the second lens. Action is the broad class; learning is the subset that gives a system agency over its own structure. This work focuses on learning because it is a research context, but the framework recognises action as the broader container.

Action
Action operates through existing structure
A robot executing a task, a pipeline processing data, a sensor recording a signal. The structure is given; the movement is execution.
The environment moves too
Structure is not changed only by our actions. The environment shifts, phenomena behave in ways we do not control, other systems respond. These external movements can degrade, disrupt, or reconfigure existing structure whether we intend it or not.
Learning
Learning reshapes structure
Training a model, calibrating a sensor, refining a processing pipeline, discovering a new composition. Where action operates through existing interfaces, learning changes the interfaces themselves.
Learning creates new interfaces
Designing a new sensor, training a new model, writing a new instrument. Each produces a structure that did not previously exist. The resulting interface is structure; the act of producing it is movement.
Learning sets direction
Choosing what to build, what to measure, which question to pursue. Direction determines which region of the interface space gets explored. It reflects values, constraints, and intuition.
The loop
Structure reveals what movement to make next
Every interface has limits — in resolution, bandwidth, or knowledge. Those limits define the frontier. What an interface fails to capture or explain becomes the next target for learning.
Movement reshapes what structure can see
An improved or newly composed interface shifts the frontier, exposing new phenomena and new limits. The cycle continues. This loop — between what we have and what we learn to build — is the engine of progress.
