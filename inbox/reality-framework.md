Interactive HTML document presenting a first-principles framework for understanding reality through two complementary lenses: structure (arrangements, patterns, interfaces through which information flows) and movement (actions, changes, and processes that reshape those arrangements). Applied to biosignal research — heart-brain coupling, physiological sensing, and adaptive interfaces.

## Core framework

**Structure** is described as interfaces — sensors, models, language, and displays are the same class of thing, differing on continuous properties (input bandwidth, prior knowledge, resolution, output fidelity) rather than kind. Interfaces compose: multiple interfaces form a combined interface with emergent properties.

**Movement** is the process that changes structure over time. Learning is the specific form of movement that reshapes structure itself — not just operating through interfaces, but improving them. The environment also moves independently of intent.

**The loop**: movement reshapes structure; structure reveals what movement to make next. This cycle — between what we have and what we learn to build — is described as the engine of progress.

## Five core principles

1. Structure and movement are two lenses, not two things — the distinction is a practical tool, not an ontological claim.
2. No categories, only properties — distinctions between sensor and model are quantitative, not qualitative.
3. Interfaces compose — the combination can perceive phenomena invisible to any component alone.
4. Causation is resolution-dependent — the arrow of causation is a property of the observing interface, not of the phenomenon itself.
5. Agency is in the conscious shaping — the framework helps distinguish what is within our control from what is not.

## Interfaces catalogued

14 interfaces are listed as a single class with continuous property metrics: ECG, EEG, fMRI, PPG (phone camera), respiration sensor, EDA (skin conductance), language/text, sound/music, screen/display, TRIBE v2 (multimodal brain prediction model trained on 1,000+ hours of fMRI from 720 subjects), cardiac gating model, somatic marker detector, entrainment model, and inter-person synchrony model.

## Compositions

Six interface compositions are described (Heart-Brain Coherence Monitor, Cardiac Residual Analyser, Somatic Decision Monitor, Cardiac-Musical Coupling Interface, Dyadic Cardiac Link, Attention Pulse mobile app). Each produces an emergent capability invisible to any single component interface.

## Movement tab (new)

Expands the second lens into three subsections:

**Action** — operates through existing structure. Includes the environment as an autonomous source of structural change (not only our actions reshape structure).

**Learning** — the subset of movement that reshapes structure itself: training models, calibrating sensors, designing new interfaces. Also covers direction-setting: choosing what to build and which region of the interface space to explore.

**The loop** — structure reveals its own limits (the frontier), which defines the next target for learning; improved structure shifts the frontier, exposing new phenomena. This cycle is called the engine of progress.

**In this work** — three concrete TRIBE v2 examples: training TRIBE v2 was learning (now structure); using it as a discovery lens is also learning; each project is movement that produces structure.
