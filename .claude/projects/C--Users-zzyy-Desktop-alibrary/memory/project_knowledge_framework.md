The knowledge library's research direction is framed by three factors:

1. **What to store** — beyond semantic meaning: structural position, temporal context, relational context, physical laws/constraints, uncertainty
2. **How to improve** — boundary awareness (what knowledge doesn't explain), cross-pollination (knowledge points interacting), environmental interaction (testing understanding against the world), compression (distilling many points into fewer)
3. **Techniques** — standard dense vectors, quantum-inspired, structural, geometric, multi-facet, neuromorphic, topological

**Why:** This framework guides what experiments to run and what features to build. The user sees the library as a testbed for exploring better knowledge representations, not just a vector database.

**How to apply:** When discussing new features or research, map them to this framework. When the user asks about improvements, think in terms of what-to-store vs how-to-improve vs techniques.
