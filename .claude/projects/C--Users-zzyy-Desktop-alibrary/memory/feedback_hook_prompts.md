---
name: Keep hook prompts concise
description: When writing agent hook prompts, keep them short — no need to elaborate on details or give examples
type: feedback
---

Keep agent hook prompts concise and to the point. Don't elaborate on specifics or include examples within the prompt text.

**Why:** User prefers terse hook definitions — the agent can figure out the details from a clear but brief instruction.
**How to apply:** When writing hook prompts, state the checks/rules as a short numbered list. Skip examples, elaboration, and detailed formatting instructions.
